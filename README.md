# E-WasteCare — E-Waste Management Website

A responsive, beginner-friendly student project built using **HTML, CSS and JavaScript**. It introduces responsible e-waste handling and includes a client-side pickup request demo.

## Features

- Responsive layout for mobile and desktop
- Navigation menu that works on small screens
- E-waste information and accepted-item cards
- Pickup request form with basic validation
- Demo success message; no backend or database required
- Accessible labels and status message

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Submit the form to test the demo interaction.

No installation, Java, MySQL, or server is required for this front-end version.

## Publish with GitHub Pages

1. Create a repository on GitHub, for example `e-waste-management`.
2. Upload the files and folders from this project (upload the contents, not the ZIP file itself, if you want the site to publish directly).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the deployment link to appear in the Pages section.

## Important note

This is an educational front-end demo. The pickup form does **not** send or save personal information to a server and is not connected to a real collection service. Do not enter sensitive personal data.
